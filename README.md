# Agencia de Turismo - Descubre Vinces

* **Estudiante:** Evelyn Eliana Cortez Contreras
* **Lugar asignado:** Vinces - Los Ríos
* **Enfoque:** Historia, arquitectura, gastronomía, río y cultura local

## Descripción del Proyecto
Sitio web promocional para la agencia turística ficticia del cantón Vinces ("París Chiquito"), enfocado en dar a conocer sus principales atractivos naturales, históricos y culturales.

## Tecnologías Utilizadas
* HTML5 (Estructura semántica)
* CSS3 (Flexbox, CSS Grid y Media Queries)
* Git y GitHub
* GitHub Pages
